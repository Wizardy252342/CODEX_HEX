## 🌍 The 4,000-Node Physical Key Ceremony

To reconstruct the 100-bit Round 2 key required for **Tier IV (`sha612x2`)**, solvers must locate and verify physical laser-engraved micro-plaques distributed across **4,000 coordinates worldwide**.

*   **Tamper Resistance:** Every physical node carries an individual `HMAC-SHA256` signature to prevent forged submissions.
*   **Fault Tolerance:** The global key incorporates error-correction redundancy, ensuring solvability even if a percentage of physical nodes are lost over time.
